# Contributing

Keep changes focused and explain the problem they solve. Include the checks you ran and any behaviour that still needs testing.

For multi-season changes, test a partly complete library as well as an empty one. Existing episode files must survive unchanged, and a download must stay incomplete if an expected episode fails to import. Check both API versions when changing profile settings.

Use a separate application data directory for development. Do not include account details, API keys, local configuration or personal library data in commits.

This fork follows Sonarr's code style and GPLv3 licence. Changes intended for the upstream project should follow its current contribution guidelines.
